# HealthOps 360: Hospital Quality, Cost & Readmission Analytics

An end-to-end healthcare analytics project that turns raw hospital records into an interactive Power BI dashboard for tracking **quality of care, cost, and patient readmissions**. Built on synthetic Massachusetts patient data generated by [Synthea](https://synthetichealth.github.io/synthea/).

![Executive Overview](docs/screenshots/page1_executive_overview.png)

---

## Business Problem

Hospital leadership needs a single view of how the organisation is performing. Three questions drive this project:

1. **Quality:** Which encounter types and conditions are associated with poor outcomes?
2. **Cost:** Where is money being spent, and which patient groups drive the highest cost per encounter?
3. **Readmissions:** Which patients return within 30 days, and what do they have in common?

HealthOps 360 answers these questions through a multi-page dashboard backed by a clean, reproducible data pipeline.

## Architecture

```
Synthea CSVs  →  MySQL (views)  →  Python (cleaning)  →  Clean CSVs  →  Power BI (model + DAX + visuals)
```

- **MySQL:** Raw Synthea tables loaded into MySQL; analytical views created to join patients, encounters, conditions and costs.
- **Python (pandas):** Cleans and standardises the view outputs (data types, nulls, date handling) and exports analysis-ready CSVs.
- **Power BI:** Star-schema data model, DAX measures, and interactive dashboard pages.

> **Note:** The Power BI → MySQL connector was unreliable in my environment, so the pipeline exports cleaned CSVs from Python and loads them into Power BI. This also keeps the dashboard portable and easy to reproduce.

## Key DAX Measures

The full list is in [`dax/measures.md`](dax/measures.md). A few examples:

```dax
Total Encounters = COUNTROWS(Encounters)

Total Cost = SUM(Encounters[TOTAL_CLAIM_COST])

Avg Cost per Encounter = DIVIDE([Total Cost], [Total Encounters])
```

## How to Reproduce

1. Generate or download Synthea Massachusetts data (CSV export).
2. Load the CSVs into MySQL and run the scripts in [`sql/`](sql/) to create the views.
3. Run the cleaning script in [`python/`](python/) to export analysis-ready CSVs.
4. Open `dashboard/HealthOps360.pbix` in Power BI Desktop and update the data source path to your cleaned CSV folder.
5. Refresh the data.
